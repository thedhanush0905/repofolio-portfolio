# Dhanush Maddila — Portfolio

Generated with REPOfolio utilizing the **developer** template style.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploy

You can deploy this Next.js project to **Vercel** with a single click:

1. Import this repository in the Vercel dashboard.
2. Click **Deploy**.
